# v2.5 实施与验证记录

预览后按用户要求恢复液态玻璃底栏，合并为四项导航，隐藏未载入歌曲的播放条，并准备发布 v2.5.0。

## 已实现
- 手机播放器和导航采用悬浮液态玻璃样式；更新及任务提示进入页面布局，不覆盖曲目。
- 专辑页按现有下载记录显示完成、进行中、失败与未入队；可仅重试失败或补充未入队歌曲。
- 曲库记录与已完成任务参与重复下载确认：取消、跳过记录、仍然下载。不凭歌名推断同一版本，也不假设文件仍存在。
- 后端在锁内复用同来源、同 ID、同目标音质的进行中或暂停任务，防止连点重复入队；不同音质和失败任务仍允许创建。
- 下载页区分目标音质与平台返回规格。只在有明确证据时标记降级；不把码率推断成 Hi-Res，也没有声称执行了本地音频实测。
- 修复下载失败原因直接显示翻译键。
- 酷狗／酷我未登录入口默认折叠，保留已登录账号管理。未宣称登录与游客权益相同。

## 验证
- 核心测试 181 通过，4 项网络测试默认忽略；Clippy 与 Tauri 编译检查通过。
- 下载统计与音质前端回归脚本通过，已加入 CI。
- 320px 浏览器演示流程验证：取消和跳过没有入队，失败重试复用原任务。
- 393px 专辑、下载和重复确认预览无横向溢出；截图使用演示数据，不代表真机或真实账号测试。

## 边界
专辑进度依赖当前下载记录，清除记录不会删除音乐，但会影响此统计；曲库记录不是磁盘存在性检查。
本版不新增酷我扫码或外部平台授权；不改变歌曲访问权限。
